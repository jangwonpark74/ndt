# Project documentation

When adding a feature, update all three of these project documents as part of the same change:

- `outputs/ndt-feature-inventory/feature_inventory.xlsx` — add or update the detailed feature inventory.
- `docs/FEATURE_DESCRIPTION.typ` — describe the feature, its behavior, and any relevant limitations.
- `docs/SOFTWARE_DESIGN.typ` — describe the implemented design, data flow, and relevant constraints.

Keep the three documents consistent with each other and with the actual implementation. Update the feature inventory counts and feature registers in the Typst documents when applicable; do not describe planned behavior as implemented.
